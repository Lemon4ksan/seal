# WIM Container Engine

`seal/container/wim` provides pure Go (zero CGO) creation, inspection, and extraction for the **Windows Imaging Format (`.wim`, `.swm`, `.esd`)** container architecture.

---

## Highlights

- **Pure Go & Zero-CGO**: 100% standard library + `seal` primitives. No external C dependencies or DLL wrappers.
- **SHA-1 Stream Deduplication**: Identical payloads across different directory paths share a single physical storage blob with automatic reference counting (`RefCount`).
- **Binary Interchange Compatibility**: Archives generated by Seal pass test (`7z t`), listing (`7z l`), and extraction (`7z x`) commands in official 7-Zip without warnings.
- **High-Fidelity Windows Metadata**: Full preservation of 64-bit NTFS `FILETIME` timestamps (Creation, Last Access, Last Write) and Win32 attribute flags.
- **Hierarchical Directory Serializer**: Breadth-First Search (BFS) directory group serializer with 8-byte alignment and null-terminated child sentinels.
- **Chunked Resource Streaming**: Transparent support for chunked XPRESS Huffman compressed blobs and linear uncompressed resources.

---

## On-Disk Structure

```
+-------------------------------------------------------+
| WimHeader (208 bytes)                                 |
| - Magic: "MSWIM\0\0\0"                                |
| - HeaderSize: 208, Version: 0x00010D00                |
| - Flags: WIM_HDR_FLAG_RP_FIX (0x80)                   |
| - LookupTable & XMLData ResHdrs                       |
+-------------------------------------------------------+
| Data Blobs (Uncompressed or Chunked XPRESS)           |
| - Unique file contents deduplicated by SHA-1 hash     |
+-------------------------------------------------------+
| Metadata Resource (Security + Directory Tree)         |
| - 8-byte Security Table (Total=8, NumEntries=0)       |
| - Root Dentry + 8-byte null sentinel                  |
| - BFS Child Directory Groups + null sentinels         |
+-------------------------------------------------------+
| Lookup Table (Array of 50-byte WimLookupEntry)        |
| - [24-byte ResHdr | PartNum | RefCount | SHA-1 Hash]  |
+-------------------------------------------------------+
| XML Data Resource (UTF-16LE with BOM 0xFEFF)          |
| - <WIM><TOTALBYTES>...<IMAGE INDEX="1">...            |
+-------------------------------------------------------+
```

## Quick Start

### Create a WIM Image
```go
package main

import (
	"os"

	"github.com/lemon4ksan/seal"
	"github.com/lemon4ksan/seal/container"
	"github.com/lemon4ksan/seal/file"
)

func main() {
	f, _ := os.Create("install.wim")
	defer f.Close()

	engine, _ := seal.DefaultEngine(container.Wim)

	f1, _ := file.New("boot/bcd", false)
	f1.WithString("sample BCD config")

	f2, _ := file.New("windows/system32/kernel.dll", false)
	f2.WithString("sample kernel blob")

	// Both files share identical bytes — deduplicated on disk!
	f3, _ := file.New("backup/kernel.dll", false)
	f3.WithString("sample kernel blob")

	_, _ = engine.WriteArchive(f, []*file.File{f1, f2, f3}, container.Config{})
}
```

### Inspect or Extract a WIM Catalog
```go
package main

import (
	"fmt"
	"os"

	"github.com/lemon4ksan/seal"
	"github.com/lemon4ksan/seal/container"
)

func main() {
	f, _ := os.Open("install.wim")
	defer f.Close()
	info, _ := f.Stat()

	engine, _ := seal.DefaultEngine(container.Wim)
	entries, xmlMeta, err := engine.OpenCatalog(f, info.Size(), "", nil)
	if err != nil {
		panic(err)
	}

	fmt.Printf("WIM XML Metadata:\n%s\n", xmlMeta)
	for _, entry := range entries {
		fmt.Printf("Entry: %s (%d bytes, isDir=%v)\n", 
			entry.Name(), entry.UncompressedSize(), entry.IsDir())
	}
}
```
