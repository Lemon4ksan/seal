**seal** — это сверхбыстрый lock-free движок архивации, компрессионный субстрат и платформа хранения данных для Go 1.27+. Он реализует формат контейнеров нового поколения **EON (`.eon`)** — оснащенный самовосстановлением Рида-Соломона над полем $GF(2^8)$, $O(1)$ LBA-поиском, микро-фреймингом (чтение файла при RAM $\le 64$ КБ), фазовым тирингом и блочной дедупликацией.

## Ключевые архитектурные гарантии

* **Мгновенный холодный старт ($O(1)$ LBA Seek):** Монтирование файловых систем контейнеров и чтение одиночных файлов быстрее **2 миллисекунд** через 32-байтный футер без полной распаковки архива.
* **Детерминированный потолок памяти ($\le 32$ МБ RAM):** Данные разделены на независимые solid-чанки размером не более 32 МБ распакованных байт. Гарантированно исключает падения `OOMKilled` в жестких квотах Kubernetes/cgroups.
* **Самовосстановление после bit-rot:** Встроенные коды стирания Коши Рида-Соломона над $GF(2^8)$ математически восстанавливают поврежденные секторы и сбойные блоки носителей.
* **Single-Instance Storage (Дедупликация):** Идентичные файлы (проверенные через BLAKE3-256) ссылаются на единый срез чанка, требуя **0 байт** дополнительного места на диске и 0 тактов CPU на повторное сжатие.
* **Блочная адресация (LBA):** Смещения на диске масштабируются по степени $2^{\text{BlockSizeShift}}$ (по умолчанию: 4096 байт / 4 КБ), обеспечивая Zero-Copy передачу через `mmap`, `io_uring` и `splice()`.
* **Zero-Alloc VFS прямо в памяти:** Создание, изменение, сортировка и монтирование виртуальных архивов в RAM в виде стандартной файловой системы `io/fs.FS`.
* **Безопасность уровня ядра:** Встроенные активные барьеры против атак Zip Slip (`../` path traversal) и декомпрессионных бомб (`42.zip`).

## Установка

`seal` требует Go версии `1.27` или выше.

```bash
go get github.com/lemon4ksan/seal
```

## Быстрый старт

### 1. Упаковка и распаковка в одну строку

```go
package main

import (
	"context"
	"log"

	"github.com/lemon4ksan/seal"
)

func main() {
	ctx := context.Background()

	// Упаковать директорию в высокоэффективный контейнер (.eon, .zip, .tar.gz, .7z автоопределяются по расширению)
	if err := seal.Compress(ctx, "./dist", "release.eon"); err != nil {
		log.Fatal(err)
	}

	// Безопасная распаковка (защита Zip Slip и бомб активна по умолчанию)
	if err := seal.Extract(ctx, "release.eon", "./output"); err != nil {
		log.Fatal(err)
	}
}
```

### 2. Целевое чтение любого файла за $O(1)$

Чтение нужного файла из многогигабайтного архива без декомпрессии всего архива:

```go
ctx := context.Background()

// Чтение конфигурационного файла напрямую в память менее чем за 2 мс
data, err := seal.ReadFile(ctx, "bundle.eon", "configs/app.json")
if err != nil {
	log.Fatal(err)
}

// Или generic-десериализация JSON напрямую в структуру
cfg, err := seal.ReadTo[AppConfig](ctx, "bundle.eon", "configs/app.json")

// Проверка целостности всех данных
err = seal.Verify(ctx, "bundle.eon")

// Отрисовка дерева иерархии архива в виде ASCII
tree, _ := seal.Tree(ctx, "bundle.eon")
fmt.Println(tree)
```

## Виртуальные архивы в памяти (VFS Builder)

Создание, мутация, шифрование и потоковая передача архивов прямо в оперативной памяти:

```go
// Создать виртуальный архив с шифрованием WinZip AES-256
archive := seal.NewArchive(
	seal.WithContainer(container.Zip),
	seal.WithCompression(seal.Deflate, 9),
	seal.WithPassword("passphrase123"),
	seal.WithSortStrategy(seal.SortNameAsc),
)

// Добавление срезов байтов, строк или ленивых потоков
archive.AddBytes([]byte(`{"status":"ok"}`), "meta/health.json")
archive.AddString("v1.0.0", "VERSION")
archive.AddLazy("dump.sql", func() (io.ReadCloser, error) {
	return os.Open("/var/dump.sql")
})

// Монтирование стандартных встроенных файловых систем Go embed
archive.AddFS(embeddedAssets)

// Мутация виртуальной иерархии
archive.Rename("meta/health.json", "status.json")

// Использование напрямую как файловой системы io/fs.FS
file, err := archive.Open("status.json")

// Стриминг сжатых данных напрямую в HTTP response или на диск
_, err = archive.WriteTo(ctx, w)
```

## Безопасность по умолчанию

1. **Активный щит от Zip Slip:** Автоматическая нормализация и проверка путей. Отклоняет любые записи, пытающиеся выйти за пределы каталога (`../../etc/shadow`).
2. **Защита от декомпрессионных бомб:** Непрерывный мониторинг коэффициентов распаковки и прерывание операции, если вложенные бомбы (например, `42.zip`) превышают лимиты безопасности.
3. **Цифровые подписи (Ed25519):** Нативное хранение подписи в TLV-структурах для защиты цепочек поставок софта от подмены.
4. **AEAD-шифрование:** Solid-чанки шифруются независимыми шифрами **XChaCha20-Poly1305** или **AES-256-GCM** с детерминированными нонсами.
5. **WinZip AES-256 и ZipCrypto:** Полная обратная совместимость с шифрованными legacy-архивами.

## Обработка ошибок

Удобная проверка ошибок с помощью встроенных предикатов:

```go
data, err := seal.ReadFile(ctx, seal.FromFilePath("archive.eon"), "app.json")
if err != nil {
	switch {
	case seal.IsNotFound(err):
		// Запись не существует в архиве
	case seal.IsPasswordMismatch(err):
		// Неверный пароль или отсутствует ключ дешифрования
	case seal.IsZipSlip(err):
		// Обнаружена попытка path traversal
	case seal.IsResourceLimit(err):
		// Превышен лимит безопасности (zip-бомба)
	case seal.IsCorrupted(err):
		// Несовпадение BLAKE3, ошибка CRC-32 или битый фрейм
	}
}
```

## Консольная утилита (CLI)

`seal` включает в себя готовую утилиту командной строки:

```bash
# Упаковать папку в высокопроизводительный контейнер .eon
seal create -o bundle.eon -l 9 ./dist

# Посмотреть записи, коэффициенты сжатия и дедуплицированные срезы
seal list bundle.eon

# Извлечь файл прямо в stdout за O(1) времени
seal cat bundle.eon config.json

# Проверить крипто-целостность и восстановить битые блоки
seal test bundle.eon

# Отрисовать терминальное ASCII-дерево архива
seal tree bundle.eon
```
