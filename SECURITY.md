# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `seal` seriously. If you believe you have found a security vulnerability in `seal` (such as archive path traversal escapes, cryptographic weaknesses, or resource exhaustion vulnerabilities), please do not report it through public GitHub issues.

Instead, please send an email to `security@lemon4ksan.com` with:
- Description of the vulnerability
- Proof of concept or reproduction script
- Affected versions and configurations

We will acknowledge receipt of your report within 48 hours and work with you on a resolution and coordinated release.
